# 投镜 · 个人投资 AI 网页演示

在 [本机 18042](http://127.0.0.1:18042/) 打开。左侧切换六个主入口。详情、研究助手、引用、策略结果和社区对照在当前页展开。

| 页面 | 演示入口 | 实际使用的能力 |
| --- | --- | --- |
| 我的投资 | 投资生涯、关键决策、长期记忆、同场回放 | 账本与策略引擎归档。按成交时间交给原研究工具，打开当时资料和后续结果。记忆保存在浏览器，可修订、撤回和导出 |
| 我的策略 | 提出条件、确认规则、运行并回放、版本与分享 | 原策略规则校验、版本库、六路径计算与策略文件导入导出。个人镜像与公开方法为教学样本 |
| 公司研究 | 经营全貌、财报与证据、估值实验、我的判断 | 原公司资料库及经营关系、报告原文定位、财务校验和估值方法。判断在确认后保存到演示库 |
| 研究社区 | 与我同图比较、模拟跟随、分享 | 归档六路径复用同一行情。本地模拟预算按所选路径的净值变化投影。分享包调用原策略导出接口 |
| 资料与账户 | 预览林远的交易文件、选择本地 CSV | 浏览器内核对导入字段与样本记录 |
| 设置 | 动效、字号、分享内容和档案导出 | 浏览器内保存演示偏好 |

右上角「功能与数据」列出各项接口及当前连接程度。「问投镜」接的是同一个本地研究运行时。框选行情后会带入证券、开始与结束日期。同一对话可继续追问并引用原依据，对话历史支持项目、归档和恢复。

## 数据口径

- 使用 2020 至 2025 年的历史日线。林远、社区人物及 54 笔成交属于教学素材。K 线和六路径共用固定日期轴，随同一个游标从左向右揭开。可在图表菜单固定最近 120 或 240 个交易日。下方指标反映全组合，个股切换只改变行情和成交标记。
- 策略计算和金融门禁沿用现有产品运行时。离线研究调用原有研究工具。自然语言策略编辑支持界面中的规则条件。
- 新 CSV 在本机解析、回放并生成成交统计卡；收益与回撤需要完整的账户资金与持仓资料。社区发布在当前浏览器保存，跟随使用模拟预算。真实账户、外部模型和真实交易属于独立接入范围。
- 视觉沿用本演示的循环背景视频和蓝橙玻璃球。素材及归档哈希记录在 `public/provenance.json`。

## 启动与验证

```sh
npm run dev
npm test
npm run build
```

本地启动需要同一工作区内的产品和公司仓库，以及产品已有的 Python 虚拟环境。`integration/runtimePlugin.ts` 将网页操作接入原协议，运行数据保存在本目录的 `.local/aligned-runtime`。静态构建可检查界面，研究、规则计算和公司接口使用本地启动入口。

## 统一生涯唤醒（2026-11-07）

欢迎页点击「唤醒林远的投镜」，或在工作台顶部点击「生涯唤醒」。原来的成交光点汇聚、玻璃球点亮、轨道展开，现已连入同一条约 32 秒的时间轴，接着播放个人生涯，再回顾记录、蓄能并旋转展开分析卡。全程共用同一个播放器，可暂停、跳到回顾、从开头重播；纯字幕，无旁白。

直接播放入口：`http://127.0.0.1:18042/?awakening=play#/investments`。正常欢迎页仍为 `http://127.0.0.1:18042/#/investments`。

首轮回顾使用已有教学档案的本地计算与证据，不调用在线模型。7/11 描述连续买入相对前一次买入的价格，保留 4 条相反样本，不当作全部下跌机会率。回撤沿用资金流调整后的净值口径。结果卡支持查看全部依据；「和投镜继续回顾」把具体成交范围与问题草稿交回原助手，待用户发送。

上传自己的 CSV 使用同一个播放器与球变卡特效，时间轴、交易条数、买卖分布、标的数量与证据来自所选文件，不使用林远的账户或财务指标。结果卡可回到资料与账户核对全部记录。只依据成交文件尚不能计算账户收益与回撤，界面会说明需要补齐的资料。

旧独立 WakeSequence 入口已移除。原 Canvas 光轨保留为可由外部时钟控制的 createTraceScene；它与 Three.js 光效、卡片和字幕都由同一个 Motion 时钟驱动。开启减少动效时直接展示对应档案的卡片。3D 组件按需加载，依赖版本固定于 package-lock.json；组件与许可见 `public/THIRD_PARTY_NOTICES.md`。
