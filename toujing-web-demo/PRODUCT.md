# 投镜：个人投资 AI 网页演示

此目录是独立网页 demo，不替换原生候选和源代码。产品范围以 ../../产品总纲/框架源数据.json 及用户最新确认的展示要求为准。

核心任务：导入投资历史，唤醒个人 AI；回到每次决策的信息环境；在对话中共创策略；在同一行情同步播放六条投资路径；逐步构建公司经营图；社区同图对照与模拟跟随；长期记忆可管理、可纠正、可导出。

固定六个入口：我的投资、我的策略、公司研究、研究社区、资料与账户、设置。复盘和多路径播放属于我的投资。一个共享助手。全部能力有可点击的本地演示流程。

展示真实性：现有六年历史行情、虚构教学交易、现有引擎的预计算路径；浏览器生成的规则实验单独注明简化假设。对话使用本地情景响应，不冒充联网模型。社区角色和跟随为合成演示，不连接真实证券账户。

进入教学档案后的默认页为“投资生涯”。按用户 2026-11-07 确认，移除重复的“我的个人 AI”页签；我的投资保留“投资生涯 / 投资经历 / 问投镜”及同场回放入口。生涯唤醒与共享助手继续保留。

投资生涯集中展示六项账户概要、资产/收益/回撤轨迹、持仓与集中度、交易统计和年度复盘。数字来自同一份账户估值、成交与投资经历档案；已结束经历用于胜率等统计，仍持有的经历单列。基金底层披露缺失时保留未知权重。优先桌面全屏，局部滚动承载窄窗口与打开助手后的内容，明细和计算口径按需展开。
