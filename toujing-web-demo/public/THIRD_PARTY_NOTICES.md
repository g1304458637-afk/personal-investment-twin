# 生涯唤醒：组件与来源

- Motion 13.1.1：统一动画时间轴、3D CSS 旋转、播放控制。MIT，完整许可见 `licenses/motion-LICENSE.txt`。官方文档：https://motion.dev/docs/animate
- Three.js 0.187.0：3D 几何、Points、Torus 与官方 EffectComposer / UnrealBloomPass。MIT，完整许可见 `licenses/three-LICENSE.txt`。参考：https://threejs.org/docs/pages/UnrealBloomPass.html 和官方 Unreal Bloom 示例。
- 蓝橙球体 `/orb.png`、原有手掌背景视频与既有 Canvas 成交光轨沿用本项目资产及代码。旧光轨改由同一个 Motion 时钟驱动，独立旧播放器已移除；未替换或复制不明社区素材。
- 生涯曲线、交易、回撤和资金拆分取 `demo-data.json` 的原有教学档案，来源身份沿用 `provenance.json`。新增本地回顾会核对日期、成交引用、年度损益与资金流，再生成文字与证据卡。
- 自传 CSV 的记录回放、买卖计数与标的统计只读取用户在本机选择的文件，不混用教学档案，也不推算缺少资料的账户收益或回撤。
- 播放过程仅显示字幕，无旁白。

自定义部分是投镜的镜头编排、档案绑定与结果卡；没有复制整套第三方产品或新建底层动画引擎。
