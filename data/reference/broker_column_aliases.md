# 券商成交导出列名映射（东方财富 / 同花顺 → generic_csv_v1）

> 诚实声明：以下映射基于 **2026 年前** 的常见券商导出版本归纳，券商随时可能
> 调整导出列名、列序或编码。`detect_broker_format` 识别失败、或 `convert_to_generic_csv`
> 报缺列/无法解析时，请改用 **generic_csv_v1 格式**（列名 `event_time, symbol, side,
> quantity, price, fee, time_precision, ...`）手工整理后导入。
>
> 仅支持 **CSV 文本**。现有导入管道 `preview_generic_csv` 只接受 UTF-8/UTF-8-BOM
> 编码的 CSV，**不支持 Excel**；xls/xlsx 请先在 Excel 中"另存为 CSV"。

## 转换规则（两种券商通用）

| 项目 | 规则 |
| --- | --- |
| 编码探测 | UTF-8 BOM → UTF-8 → GB18030，逐级回退；全部失败抛错（中文提示） |
| 时间 | 有时间列：`YYYY-MM-DD HH:MM[:SS]+08:00`，`time_precision` = `second`/`minute`；无时间列或时间为空：`YYYY-MM-DD`，`time_precision` = `date`。A股成交记录为北京时间（UTC+08:00，无夏令时），偏移量写入文件以满足 generic 对 timed 事实的显式时区要求 |
| 方向 | 买入/买/证券买入/B/BUY → `BUY`；卖出/卖/证券卖出/S/SELL → `SELL`；其余（融资买入、担保品买入、卖出开仓、申购等）抛 `ValueError`，generic 不支持 |
| 数值 | 千分位逗号、空格、"元/￥/¥"后缀自动剔除；数量为整数时输出整数形式 |
| 行序 | 保持原文件顺序；不排序、不去重（重复检测由既有管道负责） |
| 表头变体 | 全角/半角、含空格、`(...元)` 单位后缀（如 `成交金额(元)`）均可识别 |

## 东方财富（eastmoney）

| 导出列（含变体） | generic 列 | 说明 |
| --- | --- | --- |
| 成交日期 | `event_time`（日期部分） | 支持 `20241231`、`2024-12-31`、`2024/12/31`、`2024.12.31` |
| 成交时间 | `event_time`（时间部分）+ `time_precision` | 支持 `093105`、`09:31:05`、`09:31`；可缺省 |
| 证券代码 / 代码 | `symbol` | 原样保留 |
| 买卖方向 / 交易方向 / 方向 / 操作 | `side` | 见方向映射 |
| 成交价格 / 成交价 | `price` | 清洗后原样透传 |
| 成交数量 / 成交股数 / 成交份额 / 数量 | `quantity` | 整数化 |
| 手续费 / 费用 / 总费用 | `fee` | **总额列优先**：存在则只取该列 |
| 佣金、印花税、过户费、经手费、证管费、其他费、附加费 | `fee` | 无总额列时**求和合并**，不与总额列重复累计 |
| 成交编号 / 编号 / 成交序号 | `source_execution_id` | 有则透传（用于精确去重） |
| 证券名称、成交金额 等 | （丢弃） | generic 无对应事实字段；成交金额以 价格×数量 为准 |

## 费用口径说明

`generic_csv_v1` 的费用是**单字段**（`fee`，别名 `fee/commission/手续费`），下游
`fee_fact` 只有 known_nonzero / explicit_zero / unknown 三态。因此：

- 有"手续费"（总额）列 → 直接取该列（`explicit_zero` 当且仅当合计为 0）；
- 否则 → 佣金+印花税+过户费（+经手费/证管费/其他费）求和，用 Decimal 精确累加；
- 文件没有任何费用列 → 输出中不含 `fee` 列，generic 记 `unknown`（仅 warning，不阻断导入）；
- 费用单元格为空按 0 计；负数、非数字原样触发 generic 按行标记 `invalid_fee`（转换器只做格式，不做数值裁断）。
