# Real-ledger AI context

The real-account chat adapter projects `LedgerRuntime.get()` results into existing account conversation records. It does not create buys for opening holdings or call the fixed-cash replay. Monetary values retain the ledger's decimal strings and nulls. Snapshot/performance retain source dates, warnings, errors, pending assets, net external contributions and the unavailable-TWR explanation.

Account tools can read cash flows, corporate actions, canonical executions, immutable plans/notes/research and reconciliation reports. Research source CSV rows and repeat requests are omitted from chat; saved simulation reports remain labeled as simulations. User-authored plans/notes are untrusted content. The adapter cannot turn hindsight into a verified prior plan.

Episode conversations retain only the selected episode's detail, index/results and corresponding event/price references. Shared financial concepts remain available. Account snapshots, other episodes, journals and reconciliation are excluded. The standard tool receipts, scoped source fingerprint, numeric guard, grounding review, consent and validated archive remain in force.

The ledger is a distinct projection kind. Fixed-cash hypothetical/period/same-stock calculators are not offered to it. The UI routes hypothetical checks to the existing ledger research workspace. TWR and return drawdown are not manufactured from a path containing external flows. Book-cost trading PnL and period PnL from opening market value remain separate; dividends are account-level income, not newly allocated to episodes.

Context fingerprints include reconciliation runs as well as profile, events, executions, prices and journal entries. New statements and voids invalidate old answers. Price observation references are attached to valuation records; focused episodes retain only their instrument/period references.

Offline regressions cover opening-only accounts, zero cash, flows, split/missing marks, price provenance, episode isolation, stale reconciliation, ungrounded numbers and a scripted DSA turn with actual tool receipts. The packaged roundtrip also reads whole-account and focused contexts and checks fingerprint invalidation. These are offline checks, not live-model quality acceptance. No account data or credentials need to be sent to run them.
