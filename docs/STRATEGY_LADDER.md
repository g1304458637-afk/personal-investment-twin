# 策略表达力梯子（架构决策记录）

状态：**架构已锁定**（2026-09-12 用户批准）。本文记录总路线、逐层定义、红线与解冻条件；
后续任何策略表达力的扩展必须先对照本文，不得绕过。

## 总路线

**一个引擎、四层皮、逐级盖。**

- 引擎与"策略=数据"的底座不变：`StrategySpec` / `user_strategy.v1` 都是数据，
  由确定性解释器执行；任何一层的新表达力都编译回同一份数据格式。
- 用户按自身段位选层；**向下兼容是硬约束**——高层的 spec 升级（v1→v2）必须保证
  旧 spec 在新版下逐字节可运行。
- 每一层的防线不可裁剪：fail-closed 校验、点时纪律（只准向后引用）、
  未来函数自检、来源标注（user_defined / public_rule / system_execution）、
  样本量诚实。层的级别越高，防线只能更多，不能更少。

## 梯子定义

| 层 | 形态 | 表达力 | 状态 |
|---|---|---|---|
| L1 填参数 | 内置策略模板 + 参数调节 | 模板内参数 | ✅ 已交付（四策略） |
| L2 选积木 | 因子条件填空（AND 入场 / OR+止损退出 / 排序 / 仓位） | `user_strategy.v1` | ✅ 已交付（工坊 v1） |
| L3 强积木 | OR 逻辑、量类因子、加仓规则、更强排序 | `user_strategy.v2`（拟） | ⏸ 待使用证据 |
| L4 写公式 | 受限表达式 DSL（qlib/Pine 风格算子） | 表达式编译为 spec 或解释执行 | ⏸ 规划档 |
| L5 写代码 | 完整 Python 策略 | 任意逻辑 | 🚫 本产品边界外（=量化平台） |

## 逐级条件（解冻规则）

- **L3 解冻条件**：L2 上线后出现真实的"表达力不够"使用证据
  （用户明确需要 OR 逻辑 / 量因子 / 加仓），而非假设性需求。
- **L4 启动条件**：L3 稳定且有会写公式的用户诉求；参考 qlib（Apache-2.0）
  的算子语义与文档结构，许可允许代码级借鉴，须保留版权声明（NOTICE）。
- **L5**：不设解冻条件。技术上需 Python 沙箱（极高难度），产品上等于
  转型量化平台（`PROJECT_SCOPE.md` 红线），双重越界。

## 既有红线（每层都适用）

- 策略 spec 结构性禁止绑定具体证券（拒绝未知参数键，防变相荐股）；
- 不做参数寻优 / 自动调参 / 交易信号输出 / 自动交易；
- 每个自建策略自动标注"用户自建，不是经典策略，不是推荐"；
- 运行前强制未来函数自检（全量 vs 截断前缀逐字节一致）；
- 合成宇宙运行，与真实账户/真实行情隔离（引擎强制）。
