# 投镜真实账户工作台

本轮延续智谱合并主线的复工分支，在本地实现重启计划第二、三、四阶段。保留既有示例和视觉；没有连接券商、发出真实订单、调用付费模型、推送 GitHub 或替换安装目录。

## 从哪里开始

打开本轮候选应用 → 我的账户 → 数据 → **真实账本 / 复盘 / 研究 / 备份**。先在“备份与恢复”生成加密备份，再为选中的账户建立期初。没有账户时使用本机 local-user / main-account；其他新账户可先在原交易导入页建立后再设置期初。

期初日期应对应该日成交之前的快照。填入期初现金、全部期初持仓、券商总成本、当日未复权价格。期初持仓不扣现金、不伪装成买入。期初之前成交仍保留原件但不重复入账；同一期初日的成交将计入。已有期初不能覆盖：现金用“期初现金更正”，持仓用作废原记录后重新登记；每次保留审计记录。

支持单币种、只做多的 equity / etf / fund，不支持融资、卖空、期货、期权、债券乘数或自动汇率换算。其他资产类型拒绝核算。证券代码必须同时提供市场及类型，例 600000 / XSHG / equity。价格使用 **unadjusted_close**，不能用前复权或总回报价格乘当前股数。

## 第二阶段：可信账本

| 入口 | 做什么 | 需要注意 |
|---|---|---|
| 入金 / 出金 | 记外部资金流；资产和净投入同步变动 | 不计为投资收益 |
| 期初持仓 | 记录原有股数、成本和期初估值 | 账期盈亏以期初市值起算，历史持仓成本另存 |
| 拆股 / 并股 | 按新股数 / 旧股数调整数量 | 总成本不变；需除权后的未复权估值 |
| 送股 | 增加实际到账数量 | 数量填新增股数；成本总额保持 |
| 现金分红 | 除息日记应收，实付日转现金扣所填税 | amount 为总应收，不是每股金额；不猜测持股资格 |
| 补扣红利税 | 按实际扣款计现金及收入变动 | 不替用户推断税率 |
| 配股缴款 / 到账 | 先现金转待到账资产，再凭缴款编号转入股份成本 | 两步分别记，不制造虚假亏损或交易 |
| 换股 | 旧股份转成新证券及明确现金对价 | 明确填写现金对价对应原成本，不自动猜成本分摊 |
| 退市结算 | 按实际现金结算并结束持仓 | 允许结算金额为0，不用最后价格伪造卖出 |
| 资本返还 | 先减少成本，超出剩余成本计收益 | 与现金分红分开 |
| 证券转入 / 转出 | 数量成本及转移当日市值分别登记 | 以公允市值作为外部投入或取出，不把原成本当成投入 |
| 利息 / 费用 | 记录实际金额 | 缺失交易费用保留未知，不填成0 |
| 券商对账 | 比较现金、完整持仓、可选成本/市值/总资产及完整成交编号窗口 | 按提供字段判断；默认金额容差0.01、数量容差0.00000001；报告不会自动修账 |

所有登记均先预览后确认。预览绑定账户、数据、参数及CSV内容，任一变化会使确认失效。同一事件编号不可覆盖；完全相同的重复记录会跳过，内容不同会拒绝。要作废已导入成交，目标编号为 execution:成交编号。原成交仍保存，作废仅改变账本重放。存在依赖时先核实并作废依赖记录。

期间盈亏 = 期末总资产 − 期初资产市值 − 净外部投入。交易已实现/浮动盈亏另按含已知费用的移动平均成本计算，两种口径不能相加代替账户盈亏。缺价、冲突价格、未知费用或无效事件会明确标记；不会补零或发布看似精确的总资产。最后已知价格会显示估值日期。没有每次资金流前后独立估值时，精确时间加权收益率与收益率回撤保持不可用。

每日约定：期初先处理，公司行动在当日成交前处理，现金流水在当日成交后处理；这是日终账本约定，不能证明缺少的盘中时序。

## 第三阶段：长期复盘与恢复

- **长期复盘**：真实账户逐日资产、净投入、成交额、持仓数量、证券 HHI、最大单仓占总资产比，以及有来源编号的投资经历。资产曲线包含出入金，不能当成收益曲线。证券 HHI 不含现金、不穿透基金，不据此打心理或投资能力分。
- **计划与成交**：软件按当前时间保存计划及失效条件。之后关联账户内的实际成交，核对标的、方向、数量及先后时序。过去成交只能标作事后关联；只有日期的成交标作“无法核实先后”。笔记永远是事后记录，不能改成事前证据。
- **完整加密备份**：.tjbackup 含一致性SQLite事实快照、独立验证聊天库、自建策略及允许备份的界面偏好。AES-GCM加密，密码经Scrypt派生；密码至少12字符，无法找回。归档展开内容上限256 MiB。Keychain/API密钥、行情缓存、日志不进入备份，新电脑需重新配置密钥。
- **恢复**：先解密、校验哈希、数据库版本与完整性，再预览账户清单。确认后替换本机全部账户及所列偏好，不是合并。替换前在数据目录保存 restore-recovery-* 本机恢复副本；中断时下次启动先回退。浏览器偏好未完成应用时会保留待恢复标记。恢复后的本机共享记录标记撤销；已发送文件不能远程收回。

现有基于固定资金旧回放的AI解释和旧ReviewPack，不会读取新账本再输出错误金额：新账本账户转入新的确定性长期复盘/计划工作台。旧AI金融事实工具尚需单独适配公司行动及资金流；这不等同于已完成新账本AI问答验收。

## 第四阶段：研究与预交易

研究支持本地CSV，1至8个当前账户已有证券，必须是明确未复权OHLCV。用户需确认区间公司行动完整；支持拆并股、现金分红（逐股总额、税额、实付日）。配股、换股、退市等其他行动区间需拆分，不从收盘价捏造OHLC，也不自动联网补齐。数据源、文件哈希、行情指纹、锁定策略、执行假设与区间均存入本机研究记录。规范化OHLCV及公司行动输入快照也进入数据库和加密备份；原CSV移走后，可在已保存研究中按原规格重新运行，不依赖缓存或原文件路径。

| 功能 | 行为 |
|---|---|
| 时间切分验证 | 训练和样本外独立现金起步、重新暖机；单次锁定策略，不用样本外挑参数。历史上已经看过的数据不能声称真正未见或事前封存 |
| 未来数据检查 | 重建不包含后续行情及拆股调整的因果前缀，核对成交及每日记录，不一致则拒绝发布研究 |
| 敏感度 | 仅训练区间，2至6个值，按输入顺序展示，不排序或推荐最优。自建条件/公式策略目前支持佣金和滑点敏感度；内置策略支持其余已列风险参数 |
| 净基准 | 预先等额分配，共用费用、税、整手、滑点及涨跌停模型；首次收盘发信号、下一开盘尝试一次，失败留现金。与历史无费、允许碎股的描述性毛基准分开 |
| 预交易检查 | 明确假设股数、价格和费用，比较同一价格基准下的前后现金、资产及持仓；不改实际账户、不提交订单 |
| 相似历史 | 只列当前账户同标的、截止日之前已结束的最多10次经历，按结束时间排序，不声称机器学习预测 |
| 假设转计划 | 预交易假设可填入计划表，仍需补理由、失效条件并预览确认 |

预交易不会确认券商冻结资金、T+1可卖数量、停牌、涨跌停或真实成交资格。研究标的池来自当前账户，存在回顾选择及幸存者偏差；用户提供公司行动的完整性未经外部核实。分红计入研究净值，平仓胜率和利润因子仍以交易损益为口径。

## CSV示例

同目录 ledger_templates/ 全部为 SYNTHETIC 测试材料，不能当成真实证券事实导入正式账户。

1. events.csv：现金流水/公司行动。每行唯一event_id；effective_date为实际生效日，cash_dividend另填ex_date。可选sequence明确同类同日顺序。
2. unadjusted_prices.csv：通过原行情导入页导入。price_type必须为unadjusted_close。
3. statement.csv：每行同一as_of与currency；一条cash行、全部position行、可选完整execution行。提供成交核对时填写executions_from；明确零成交可在cash行填execution_refs_complete=true，且无execution行。ID使用券商source_execution_id；不得用金额和日期猜身份。
4. research_ohlcv.csv：bar行是未复权OHLCV；action行说明拆股或逐股现金分红。来源在运行时填写。样例用合成日期和价格。
