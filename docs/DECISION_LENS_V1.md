# Decision Lens v1：把方法放进真实投资历史

## 范围与产品入口

“我的投资 → 一轮投资 → 策略复盘”。同一张历史图、同一组成交、同一组回放持仓保持不变。方法卡片切换固定规则，逐笔时间线选择操作，右侧解释“实际做了什么 / 按该规则怎样 / 哪个条件不同”。点击“查看实际操作”仍打开原来的真实状态抽屉。

这是历史操作的规则对照，不是另起一条策略收益曲线。没有新建订单、模型请求或行情网络请求；没有改动交易数据、盈亏算法、账户权重或原有对比模块。

## 三套教学模板

这不是完整 CAN SLIM、Oliver Kell、海龟策略，也不是一套替用户选好的赚钱策略。通用指标与明确的投镜教学规则组合，参数固定且有版本。

| 模板 | 用到的数据 | 具体口径 |
|---|---|---|
| 20 日均线趋势 | 操作日前最新收盘价与 20 个有效日收盘观察 | 高于均线时允许开仓/持有/加仓；低于时空仓等待、持仓减仓/退出；相等时等待/持有。只核对已发生操作，不生成数量。 |
| 20 日收盘突破 | 操作日前最新收盘价，与它之前的 20 / 10 个收盘观察 | 严格突破此前 20 个收盘高点时允许买入；有持仓且跌破此前 10 个收盘低点时允许卖出；否则等待/持有。不以当日高低价或成交量冒充已有数据。 |
| 加仓成本纪律 | 本次实际买入价格、操作前持仓与回放平均成本 | 只检查已有持仓后的买入：买入价不低于操作前成本为吻合，低于为分歧。建仓/卖出不适用。它是成本纪律模板，不代表所有低于成本加仓都不合理。 |

“吻合 / 分歧”只相对于当前选择的规则；不是交易好坏或投资能力分数。不同方法可能对同笔操作给出不同观察。

## 时间与数据边界

- 日线严格取 `date < execution.market_date`。规范成交的交易所市场日期优先，不截 UTC 时间字符串冒充本地交易日。
- 不使用操作当天收盘价，也不使用后续结果推定当时规则。
- 历史导入数据可能为后来复权的数据版本；日前截断不能提供公司行为的完整 point-in-time 保证，界面保留说明。
- 有效观察不足、不唯一或口径冲突时输出不足，不伪造缺失行情。20 个有效日收盘观察不等于已验证的连续 20 个交易所交易日。
- 成本模板只用实际成交和操作前成本，避免把调整后的市场价格与原始成本直接混算。
- 方法版本、参数、输入指纹随结果返回；输入指纹不是数字签名，也不是外部行情真实性认证。

## 实现位置

- `src/lenses/history.py`：小型固定模板规则引擎，确定性输出条件、方向解释、有效日期和输入指纹。
- `src/presentation/runtime_episode.py`：在现有 `episode.get` 投影中附带 `lens_review`，原有回放与财务字段不变。
- `scripts/export_episode_lenses.py`：从统一示例生成独立 Lens 资料，使用同一 Python 引擎，不改写大体积原示例。
- `apps/desktop/src/data/episodeLens.ts`：核对 schema、账户/证券/episode、逐笔执行与状态、日前截止；不在浏览器重新计算信号。
- `apps/desktop/src/pages/PositionEpisodePage.tsx`：新增页签；保留原图表实例，图上操作标记与方法详情联动。所选方法与操作写入 URL 查询参数。
- `apps/desktop/src/components/review/DecisionLensPanel.tsx`：方法卡片、逐笔时间线、实际/规则对照、条件明细。

## 参考而非整包搬入

通用指标参考高认可度 TA-Lib 的官方定义：

- [SMA / Simple Moving Average](https://ta-lib.github.io/ta-lib-python/func_groups/overlap_studies.html)
- [滚动 MAX / MIN](https://ta-lib.github.io/ta-lib-python/func_groups/math_operators.html)

本阶段没有复制新第三方源代码或增加依赖；使用已有 pandas 对有限日线计算 mean/max/min。复杂指标后续再接成熟引擎；当前额外引入整个量化平台不会替代“逐笔历史决策与规则对应”这层投镜自己的逻辑。星数不代表规则有效性，也不代表本项目集成自动稳定。

## 验证与后续

测试覆盖未来行情扰动、当天排除、市场日期、窗口不足、冲突/缺失、跨账户/证券状态、实际账本不变、模板切换与坏 URL。真实账户仍需现有导入链路提供规范成交和行情。

未包含：自定义因子表达式、完整策略收益回测、参数优化、AI 个性化推荐、公司行为 point-in-time 数据服务、自动交易。后续沿同一方法定义扩展，不能把这三套教学模板称为完整量化闭环。
